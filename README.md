# הקוף והמספרים

משחק ללימוד ספירה וזיהוי ספרות עד 10, לילדה בת 5.

- `index.html` — המשחק כולו בקובץ אחד (איורים מוטמעים). עובד במחשב ובטלפון.
- `make_voice.py` — אופציונלי: מקליט את כל המשפטים בקול עברי טבעי ויוצר `index-voice.html`.
  ```
  pip install edge-tts
  python make_voice.py index.html
  ```
