# הקוף והמספרים

משחק ללימוד ספירה וזיהוי ספרות עד 10, לילדה בת 5.

- `index.html` — המשחק לשחק בו (עם קול מוקלט). נוצר אוטומטית — לא לערוך ידנית.
- `game.html` — קוד המשחק. כל שינוי במשחק נעשה כאן.
- `make_voice.py` — מקליט את כל המשפטים בקול עברי טבעי.

## הקול נוצר לבד
בכל פעם ש־`game.html` או `make_voice.py` משתנים, GitHub מריץ לבד את ההקלטה (לשונית Actions)
ומעדכן את `index.html` עם הקול בפנים. לוקח 2–3 דקות. אפשר גם להריץ ידנית:
Actions ← "הקלטת קול למשחק" ← Run workflow.
